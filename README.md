### ⚡ 强大的待办功能

#### 1. 智能重复提醒

- **每天**：选定时间每日循环。

- **月度时间轴**：以时间轴方式展示待办，支持侧边栏跟踪、快速滚动与月份跳转。

- **随机提醒**：支持在指定时间范围内随机触发提醒，适合久坐站立、喝水等健康习惯。
